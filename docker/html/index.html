Flasher

Web Serial is not available in this browser. Use Firefox 151+, Chrome, Edge or Opera.

On Linux, Chromium installed as a snap does not see any serial ports until USB access is allowed. Run this once, then restart Chromium completely: 

sudo snap connect chromium:raw-usb

Snap runs Chromium in a sandbox that blocks access to hardware. The command connects the raw-usb interface, which Chromium already declares, so the sandbox allows USB devices including USB serial ports. It needs sudo because it changes the sandbox permissions. A page still gets only the device you pick in the browser dialog. It can be undone with sudo snap disconnect chromium:raw-usb.
